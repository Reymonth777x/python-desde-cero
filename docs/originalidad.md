# Originalidad Total — Python desde Cero

## Política de originalidad

Todo el contenido de la plataforma **Python desde cero** es de elaboración propia e independiente. No está derivado de, afiliado con, ni certificado por Cisco Networking Academy, Cisco, PE1 (Python Essentials 1), PCEP ni ningún otro curso, programa o institución de terceros.

## Elementos propios

- **Nombre**: Python desde cero
- **Paquete**: `python-desdecero`
- **Logo**: SVG escrito a mano, símbolo y wordmark propios
- **Tipografía**: Familias de código abierto autoalojadas (licencia OFL)
- **Textos**: Redactados en español neutro, apto para Costa Rica y Latinoamérica
- **Temas visuales**: 6 temas + Sistema, con paletas de color propias
- **Ilustraciones y personajes**: Dibujados por código (SVG/Canvas), sin imágenes protegidas
- **Sonidos**: Generados con Web Audio API, sin archivos de audio externos
- **Contenido del curso**: cuatro módulos principales y una extensión práctica opcional; el catálogo vigente es la fuente del recuento exacto
- **Juegos**: no hay ningún juego publicado en el producto actual; los prototipos retirados no forman parte de la oferta

## Elementos excluidos (prohibidos)

- Logo o colores de marca de Python (marca registrada de Python Software Foundation)
- Nombres, temas o ilustraciones de juegos comerciales existentes
- Contenido copiado o parafraseado de cursos, libros o sitios de terceros
- Avisos de "no afiliado" a Cisco u otras instituciones
- Estadísticas o testimonios inventados

## Declaración de autoría

Todo el código, texto, diseño y contenido de esta plataforma ha sido creado específicamente para **Python desde cero**. El proyecto es educativo, gratuito para el estudiante y de código abierto.

## Verificación

Ejecutar `npm run check:originality` para verificar que no aparecen términos prohibidos en el repositorio. Este script se integra al proceso de build de CI.
